# AI 투자 프롬프트 스튜디오

매수자가 자신의 조건을 점검하고, 후보 단지를 비교하고, 계약 직전까지 확인할 질문을 단계별로 복사해 활용하는 Next.js 앱입니다.

## Vercel 배포

`crenciasea7-dot/teacher-tools` 저장소에 이 폴더를 올린 뒤 Vercel 프로젝트의 **Root Directory**를 `ai-invest-prompt-studio`로 지정하세요.

- Framework: Next.js
- Build Command: `npm run build`
- Environment Variables: 없음

프롬프트에는 개인 금융정보를 최소한으로 입력하고, 최종 법률·세무·대출 판단은 공식 자료와 전문가 검토를 거쳐야 합니다.
