# RONE 주간 자본 분석 대시보드

주간 순자산 흐름, 자산 배분, 투자 여력, 다음 주 우선순위를 한 화면에서 보는 Next.js 앱입니다.

## Vercel 배포

GitHub 저장소 `crenciasea7-dot/teacher-tools`에 이 폴더를 올린 뒤, Vercel 프로젝트 설정에서 **Root Directory**를 `rone-weekly-capital-dashboard`로 지정합니다.

빌드 명령은 `npm run build`, 프레임워크는 Next.js입니다. 별도의 환경 변수는 필요하지 않습니다.

현재 데이터는 화면 검토용 예시입니다. 실제 자산 데이터 연동 전에는 코드에 넣지 말고, 별도 DB 또는 개인 스프레드시트 연동으로 교체하세요.
