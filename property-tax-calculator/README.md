# 보유세 계산기

공동주택 공시가격을 입력해 2026년 재산세·종합부동산세와 2027·2028년 비교 시나리오를 보여주는 정적 웹 앱입니다.

## 배포 환경 변수

Vercel 프로젝트에 다음 값을 **Sensitive** 환경 변수로 설정합니다.

```text
VWORLD_API_KEY=브이월드 개발키
```

값은 브라우저로 전달되지 않습니다. `/api/address-search` 서버 함수가 주소 후보 검색에만 사용합니다.

## 계산 원칙

- 2026년 1세대 1주택 재산세 과세표준: 공시가격 구간별 43% / 44% / 45%
- 그 밖의 주택 재산세 과세표준: 60%
- 실거주 여부: 이 앱의 2027·2028년 1주택 거주 가정에만 반영
- 보유기간: 보유세의 이 비교 산식에는 직접 반영하지 않음

실제 세액은 세대 판정, 주택 수, 과세특례, 지역별 부가세 및 확정 법령에 따라 달라질 수 있습니다.
