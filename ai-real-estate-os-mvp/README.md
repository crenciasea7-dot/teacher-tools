# 집값연구소 — AI 부동산 투자 OS

호가·실거래·계산·추정·전문가 의견·확인 필요를 분리해 보여주는 로컬 우선 부동산 검토 도구입니다. 투자 결정을 자동으로 내리지 않으며, 사용자가 확인해야 할 자료와 질문을 먼저 드러냅니다.

## 1차 MVP

1. 아파트 매수·매도 적정가격 분석
   - 호가와 실거래 가격대 분리
   - 1층·필로티·일반 저층 등 비교조건 기록
   - 중복 광고 후보 표시
   - 매수·매도 가격 검토 구간과 단기 관찰 신호
2. 재개발·재건축 초투 후보 검색
   - 초투, 공시가격, 사업종류, 진행단계 필터
   - 계약 시 필요현금과 예상 총투 분리
   - 권리·분담금 등 누락값 경고
3. 매물 캡처 여러 장 비교
   - PNG·JPG·WebP 다중 업로드
   - 한국어·영어 로컬 OCR
   - OCR 원문 수정, 비교표, 6칸 검증 결과
   - 이미지 실패 시 텍스트 붙여넣기

## 로컬 실행

필수 환경은 Node.js 22.13 이상입니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

검증:

```bash
npm test
```

## 데이터와 개인정보

- 실시간 매물 크롤링, 유료 API, 사용자 로그인, 클라우드 저장을 사용하지 않습니다.
- 업로드 이미지는 현재 브라우저 세션에서만 처리하며 외부 OCR 서버로 보내지 않습니다.
- OCR 작업에 필요한 worker, WASM core, 한국어·영어 학습 데이터를 `public/ocr/`에 포함했습니다.
- 샘플 후보와 가격은 익명화된 고정 사례이며 실제 투자 근거로 사용할 수 없습니다.
- 사용자가 입력한 광고·실거래·권리 정보에는 출처와 확인일을 함께 입력해야 합니다.
- `데이터 원칙 저장`은 앱의 검증 원칙을 로컬 JSON으로 내려받습니다. 분석 기록 백업은 후속 범위입니다.

## 계산 규칙

- 실거래와 호가는 별도 가격대로 계산합니다.
- 5건 이상이면 25% 지점·중앙값·75% 지점을, 2~4건이면 최저·중앙·최고를 사용합니다.
- 1건 이하는 가격대를 만들지 않습니다.
- 계약 시 필요현금은 `매매가 - 승계 임대보증금 - 확인된 승계대출 + 즉시 부대비용`입니다.
- 누락값은 0원으로 확정하지 않고 결과에 `확인 필요`로 함께 표시합니다.

## 한계와 확인 필요

- OCR 결과는 이미지 품질과 글꼴에 따라 틀릴 수 있으므로 반드시 원문과 대조해야 합니다.
- 동·층·향·조망·수리 상태의 가격 조정은 자동 감정이 아닙니다.
- 조합원 분양자격, 권리산정기준일, 지위 양도 제한, 현금청산, 토지거래허가, 세금·대출은 공식문서 및 관계기관·전문가 확인이 필요합니다.
- 미래가격은 자동 예측하지 않습니다. 주변 신축 가격과 가정을 입력한 뒤 약세·기준·강세 시나리오로 확장할 예정입니다.
- CSV 가져오기, 분석 기록 재열기, PDF 출력, 실제 공공데이터 연결은 후속 범위입니다.
